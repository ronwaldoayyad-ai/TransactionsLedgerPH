Build metadata, routes, package versions, palette tokens and test-suite filenames are generated by tools/documentation-inventory.cjs through the Vite virtual module. Narrative documentation needs review with behavior changes. schema-catalog.json is a read-only metadata snapshot with its own capture timestamp; refresh it after schema changes and never include row data, secret values or object contents. This is not a privileged browser connection to production.

Vercel excludes test/migration source folders and environment examples from uploads. source-catalog.json retains only their filenames, source hashes and public configuration names. After changing those sources, run `node tools/documentation-inventory.cjs --capture` from the complete checkout and commit the refreshed catalog. A unit check compares it with the real sources. Hosted builds use this catalog without reading private environment files or uploading excluded folders.

These documents are the current map/contracts. Actual CI/release evidence owns pass/fail status; Git and release/incident records own history. Existing companion feature notes below may describe earlier milestones. If those notes conflict, verify against the current implementation and update the canonical section above; do not silently treat historical preparation instructions as current production status.

## Requirements and acceptance

The documents use stable business, functional, quality and user requirement IDs. [TDD.md](TDD.md) defines acceptance and recovery scenarios. [AI-Setup.md](AI-Setup.md) explains OpenRouter’s free-model configuration and FAQ maintenance. [Architecture.md](Architecture.md) describes service hosting and security boundaries.

No borrower names, credentials, bank details, payment proofs or private ledger exports belong in the documentation or project graph. Approval of financial decisions remains with the lender.

## Change control

Update the relevant requirements and flow documents with every behavior change. Record affected requirement IDs, tests, migration effects and restart instructions. Keep FAQ text aligned with implemented navigation. Review legal notices when data destinations, retention or AI processing change. Update Graphify using the canonical source scope, excluding credentials, generated builds and private exports.
